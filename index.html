About Color Palette Studio

Color Palette Studio is a lightweight utility built for frontend developers, UI designers, and digital creators who need accurate hexadecimal color combinations without workspace clutter. Every swatch renders true-to-code sRGB colors alongside instant clipboard actions and non-destructive color locking.

Format 6-Digit Hexadecimal (#RRGGBB)
Persistence Local Browser Storage (Up to 5 Palettes)
